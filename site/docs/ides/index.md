# IDE Setup

Pick your IDE. Most support **both** integration paths (Claude Code for agentic work + a native BYOM agent for chat/completions).

| IDE | Native AI | Via Agent |
|---|---|---|
| [VS Code](vscode) | Copilot BYOK | Claude Code, Cline, Continue |
| [JetBrains](jetbrains) | AI Assistant (BYOM) | Claude Code, Cline |
| [Cursor](cursor) | Native BYOM | Claude Code |
| [Antigravity](antigravity) | — | Claude Code |
